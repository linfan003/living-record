# 复核过期记录

## 步骤

1. 读取 `records/*.md`。
2. 收集两类：状态是「待复核」的，以及复核日期早于今天的。
3. 按复核日期从早到晚列出。每行包含相对路径、范围、出处、复核日期、一句话标题。
4. 默认只在回复里列出。用户明确说「写进文件」时，才把清单写到记录根的 `review.md`，并注明生成时间。
5. 用户确认某条仍然成立：把状态改回「有效」，把复核日期改成用户给出的新日期。用户没给新日期时，从今天起加 90 天，并告诉用户这个日期。
6. 用户确认某条不再成立：状态改为「已停用」。正文保留。

不把过期记录改成有效，除非用户对那一条明确点头。
